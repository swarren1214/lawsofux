[~1 min] This is session one: how people decide. Seven laws, all about the same idea, which is that attention and memory are a limited budget. [Point to the animation] The animation is the whole module in one picture. There’s one decision in the middle, and options orbiting around it. Every one of those options pulls a little bit of attention. So does every label, every field, every banner we add. None of them is free. Over the next seven laws we’ll look at where that budget goes and how to stop wasting it. [Ask the room, show of hands: “Who’s used an app this week where you had no idea which button to press?”] [Pause for hands.] Yeah. That’s what this module is about. We’ll start with Hick’s Law, because it’s the easiest one to see and the easiest one to measure.
