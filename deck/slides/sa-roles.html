[~2 min] Selective Attention on Monday. Product, here’s the uncomfortable truth: if every screen has five “important” messages, none of them are important. Pick the one thing per screen that must not be missed, and design around protecting it. [Pause] Engineering, this is really a design-system question. Alert, warning and safety components need a visual language that promotions are never allowed to use. And that’s something you can guard in code review. If someone reaches for the promo banner to show a warning, that’s a flag. QA, this one’s tricky, because knowing an alert exists ruins the test. If you go in looking for it, you’ll see it every time. The only honest check is handing the flow to someone who doesn’t know what to look for, then asking afterward, “Did you see anything about a dog?” [Ask the room: “Who could we borrow for that kind of test, someone who’s never seen the flow?”] [Let a couple of people answer.] Okay, that’s all seven laws for Module 1. Let’s pull it together.
