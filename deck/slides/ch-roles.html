[~2 min] Chunking on Monday morning. Product, this one’s about finding the natural groups. And the key word is natural: groups that match how users already think, not how our database is organized. A quick card sort with a few real users is a fast way to find them. [Pause] Engineering, input formatting is chunking you can actually ship. Phone numbers, card numbers, codes: group them as people type, and make sure that grouping survives copy and paste. That second part is where a lot of forms break. QA, try the five-second test. It’s a real usability method, not something I made up. Show someone a screen for five seconds, hide it, and ask what it was for and what stood out. If they can’t tell you, the chunks aren’t working. [Ask the room: “QA, which screen would you run the five-second test on first?”] [Let a couple of people answer.] Next up is the last law in Module 1, and it’s the one that can actually get someone hurt if we ignore it: Selective Attention.
