[~2 min] Proximity on Monday morning. Product, grouping is an information architecture decision before it’s a visual one. Decide what belongs together first, then make sure the layout says so. [Pause] Engineering, most proximity bugs are actually spacing bugs. A spacing scale in the design system, with smaller values inside groups and bigger values between them, makes the right layout the default. Hard-coded margins drift over time, and that’s how we end up with forms like Kestrel’s. QA, “whose label is this?” is a quick visual check you can run on every form. And it’s especially worth running at different screen sizes, because responsive layouts often collapse the very gaps that made the grouping clear. [Ask the room: “QA, do we test our forms at small screen sizes today?”] [Let someone answer.] Next up: what do you do when space alone isn’t enough? That’s the Law of Common Region.
